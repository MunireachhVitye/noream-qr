# Noream QR

A simple offline QR code scanner built with Electron.

## Features

- 📷 Scan QR codes using your camera
- 🔌 Works offline
- 🪟 Windows support
- 🍎 macOS support
- 🔒 No analytics
- 📡 QR data is processed locally
